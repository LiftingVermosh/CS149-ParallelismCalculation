# 多通道直方图

高效的多通道直方图计算是许多 GPU 工作负载中的基本操作。当众多线程和通道竞争更新相同的直方图箱时，朴素的方法会遭受过度的原子竞争和糟糕的内存访问模式。优化这一计算体现了关键的 GPU 编程概念，如并行性、共享内存和同步。一个精心设计的直方图内核成为高性能的基础构件，有益于下游任务，如图像处理、特征提取和数据预处理。

---

## 输入

- **num_bins**
  直方图的箱数。

- **array**
  一个形状为 **`[length, num_channels]`** 的张量，包含范围在 `[0, num_bins - 1]` 内的整数值。

### 测试用例参数

- **num_bins:** `256`
- **array shape:** `[1048576, 512]`

---

## 输出

- **histogram**
  一个形状为 **`[num_channels, num_bins]`** 的张量，其中
  `histogram[c][b]` 表示值 **b** 在通道 **c** 中出现的次数。

### 测试用例输出形状

- **histogram:** `[512, 256]`

---

简而言之，对于输入张量的每个通道，内核生成一个离散直方图，汇总该通道中所有条目的值分布。
